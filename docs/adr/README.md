# 架构决策记录（ADR）索引

> 模板：[`ADR-TEMPLATE.md`](ADR-TEMPLATE.md) · 规范：见 [`../CONTRIBUTING.md`](../../CONTRIBUTING.md) 第 5 节

ADR 记录**不可从代码反推**的决策：为什么选它、放弃了什么、代价是什么。这是「架构级开发」最直接的证据，也是面试与客户沟通时的主要材料。

## 状态口径

| 状态 | 含义 |
|---|---|
| `proposed` | 已提出，待拍板 |
| `accepted` | 已生效，实现须遵循 |
| `superseded` | 被后续 ADR 取代，正文保留不改 |

🔴 **历史 ADR 正文不可修改**。推翻旧决策时新增一篇并在旧文标注 `superseded by ADR-XXXX`。
